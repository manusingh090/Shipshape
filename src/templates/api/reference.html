OpenAPI

The whole API as an OpenAPI 3.1 document: every operation with its parameters, request body, answer and errors, the webhook deliveries, and the older /api/ routes.

Load it into any OpenAPI tool (a client generator, Postman, Insomnia, a mock server); none of them needs the internet to read it. It's built from the same table as this page, and the tests check every answer the API gives against it.

curl -o openapi.json {{ base }}openapi.json

Signing in

Make a token on your account page, then send it with every request:

curl -H "Authorization: Bearer ss_..." {{ base }}me

From a signed-in browser on this site, JSON requests also work with the session cookie. Uploads need a token.

Answers

JSON everywhere. Lists come as {"count", "page", "pages", "results"}; ?page= and ?per_page= (up to 200) page through them.

A refusal is {"error": "code", "detail": "a sentence for a person"} with the right status: 400 invalid (with fields), 401 not signed in, 403 not allowed or outside a window, 404 not there or not yours to see, 429 slow down.

Dates are UTC ISO 8601. Where the page asks for a time in the event's zone, send either that (2026-03-01T18:00) or ISO with an offset.

Webhooks

Everything that goes into an event's activity log can be sent to your own URL as it happens, signed. Organizers set them up in the console; the endpoints are under Webhooks.
