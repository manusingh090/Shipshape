How delivery works

A JSON POST with the entry's type, time, who did it, what happened and the team or project it concerns. Headers: Shipshape-Event, Shipshape-Delivery (unique, so you can ignore repeats) and the signature.

Answer with any 2xx. Anything else is tried again after {{ backoff|join:", " }} minutes, then given up. {{ disable_after }} given-up deliveries in a row switch the webhook off. Redirects aren't followed, and addresses on the server itself are refused.
